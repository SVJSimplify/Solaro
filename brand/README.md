# Solara brand assets

Mark = the in-app sun symbol (`#m` in `index.html`). Wordmark text is outlined (Outfit 600), so no font is needed.
Palette: coral `#F25C54`, cream `#FFF6E5`, deep teal `#183F3D`.

| File | Use |
|---|---|
| `solara-logo-light-bg.svg` / `-dark-bg.svg` | Lockup (mark + wordmark) |
| `solara-mark-coral.svg` / `-cream.svg` | Mark alone |
| `solara-favicon.svg`, `solara-favicon-512.png` | App/tab icon (simplified, coral tile) |

Regenerate: `python3 scripts/brand.py <outfit-latin-600-normal.woff> brand`.
